## 🚀 Sobre o Projeto

Este portfólio não é apenas um site estático, mas uma aplicação web moderna construída com o ecossistema Laravel e Vue.js. Ele foi projetado para oferecer uma experiência de usuário premium, com foco em performance e design limpo.

### 🛠️ Tecnologias Utilizadas
- **Backend**: Laravel 11 (PHP 8.2+)
- **Frontend**: Vue.js 3 com Inertia.js
- **Estilização**: Bootstrap 5 + Custom CSS (Glassmorphism & Bento Grid)
- **Banco de Dados**: MySQL (gerenciado via phpMyAdmin/WAMP)
- **Ferramentas**: Vite, Composer, NPM

## ✨ Funcionalidades Principais
- **Design Moderno**: Layout estilo "Bento Box" para visualização clara de projetos e habilidades.
- **Gestão de Projetos Privados**: Sistema inteligente que exibe "Case Studies" para projetos corporativos internos que não podem ter links públicos, mantendo a confidencialidade e demonstrando capacidade técnica.
- **Linha do Tempo Profissional**: Histórico detalhado de experiências (FutFanatics, E-Comp, etc.).
- **Responsividade Total**: Experiência otimizada para Desktop e Mobile.

## 🔧 Como Executar Localmente

Se você deseja explorar o código ou rodar este projeto na sua máquina:

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/JoaoRampazzo/my-portfolio.git
   ```

2. **Instale as dependências**:
   ```bash
   composer install
   npm install
   ```

3. **Configure o ambiente**:
   - Copie o `.env.example` para `.env`
   - Gere a chave da aplicação: `php artisan key:generate`
   - Configure suas credenciais de banco de dados no `.env`

4. **Prepare o banco de dados**:
   ```bash
   php artisan migrate --seed
   ```

5. **Inicie os servidores**:
   ```bash
   php artisan serve
   npm run dev
   ```
